## What it does

This is a complete SaaS invoicing system built with PHP and MySQL. One install runs many businesses. Each company signs up, gets its own separate data, and works on a subscription plan that you control as the platform owner. Inside each company, staff create invoices, track stock, take payments and read reports from one central dashboard. Built as a real multi-tenant SaaS Platform owner panel: manage companies, plans, trials, subscription periods and payment references. Each plan decides which modules a company can open. Company roles: business Admin, Manager and Employee, plus custom roles with a View / Add / Edit / Delete permission matrix. Multi-branch: staff can be limited to their own branch, managers can switch between branches, and stock moves between branches through transfers.
